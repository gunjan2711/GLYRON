# GLYRON
A gesture-controlled interactive web application featuring virtual object manipulation and Air Canvas drawing using hand tracking and computer vision.

## Features

*  Real-time hand gesture detection
*  **Air Canvas** — draw in the air using your index finger
*  Gesture-based interaction with virtual elements
*  Webcam-based hand tracking
*  Real-time interaction

##  Technologies Used

* HTML
* CSS
* JavaScript
* MediaPipe
* Web Camera API
* HTML Canvas

##  Air Canvas

Glyron includes an **Air Canvas** that allows users to draw digitally using their finger movements.

The webcam detects the user's hand, tracks the index finger, and converts its movement into digital strokes on the canvas.

### How it works


Webcam
   ↓
Hand Detection
   ↓
Hand Landmark Tracking
   ↓
Index Finger Detection
   ↓
Finger Movement
   ↓
Digital Drawing


##  Objective

The goal of Glyron is to explore **gesture recognition and touch-free Human-Computer Interaction (HCI)** using computer vision.

##  How to Run

1. Open the Glyron project in a browser or local development server.
2. Allow webcam access when prompted.
3. Place your hand in front of the camera.
4. Use your hand gestures to interact with the application.
